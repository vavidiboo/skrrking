# Skull King UI Style Audit

## Summary

현재 UI는 "카툰틱 해적 테마"의 재료는 충분히 갖고 있지만, 화면별 완성도와 시각 언어의 일관성이 끊기는 구간이 있습니다. 홈 화면은 비교적 게임적인데, 로비 설정/검색/결과 모달은 운영 툴에 가까운 질감이 남아 있어 전체 경험이 하나의 게임처럼 이어지지 않습니다.

## Practical Issues

- 테마 일관성 분리
  홈 화면은 게임 로비처럼 보이지만 `Find Room`, 비밀번호, 결과 계열 모달은 기본 패널 스타일 위주라 같은 제품 안의 다른 앱처럼 느껴집니다.
- 정보 우선순위가 실무적으로 불안정
  방 찾기에서 내부 세션 ID가 이름보다 먼저 읽히고, 토글 상태는 개별 설정보다 서버 상태가 언제 되돌아오는지에 더 크게 좌우되어 신뢰감을 떨어뜨립니다.
- 카툰 스타일의 핵심 리듬 부족
  큰 실루엣, 과장된 대비, 보상감 있는 하이라이트, 피드백 애니메이션이 홈 이외의 화면에서는 약합니다.
- 게임성 전달 장치 부족
  해적 세계관을 설명하는 아이콘 체계, 라운드/위험/보상에 대한 상징 장치, 카드 전투의 긴장감을 올리는 모션 장치가 부족합니다.
- 상태 전환 UX가 밋밋함
  로딩, 매칭, 라운드 종료, 최종 승패, 재접속, 비밀번호 입력 같은 핵심 순간이 대부분 같은 모달 톤으로 처리되어 임팩트가 분산됩니다.

## Missing Or Underserved Surfaces

- 부트 스플래시/액션 스플래시
  첫 인상이 너무 시스템 로더에 가깝고, 게임에 들어간다는 기대감을 충분히 만들지 못합니다.
- 방 찾기 empty/loading/error 상태
  실제 서비스에서는 빈 상태, 로딩 중, 재시도 실패 상태가 자주 보이는데 현재는 메시지 표현이 기능 중심입니다.
- 라운드 결과 / 게임 결과 / 이벤트 결과의 역할 분리
  화면은 존재하지만 각각의 감정선이 다르게 설계되어 있지 않아 라운드 성공, 역전, 최종 승리의 차별화가 약합니다.
- 관전자/재접속 상태
  기능은 있으나 카툰틱 톤의 read-only, reconnect grace, 관전자 배지 체계가 더 필요합니다.
- 공유/초대 플로우
  해적 테이블에 친구를 불러 모은다는 판타지가 디자인으로 충분히 풀려 있지 않습니다.

## Direction

- 모달군을 전부 "선실 카드"처럼 재정의하고, 제목-서브카피-상태배지-행동 버튼 구조를 통일합니다.
- 결과 화면은 라운드 결과, 최종 승리, 재접속 경고를 각각 다른 색/모션/아이콘 체계로 구분합니다.
- 카툰 스타일은 단순히 둥근 모서리보다 큰 실루엣, 금빛 보상 포인트, 선명한 그림자, 과감한 상태 배지를 통해 강화하는 편이 실무적으로 유지보수도 쉽습니다.

## Asset Usage Plan

- 적용 완료
  `Screen/Result/Final` 계열 선실 이미지를 최종 결과 모달의 승리/패배 히어로 배경으로 연결했습니다.
- 홈 화면
  따뜻한 선실 이미지는 메인 CTA 뒤 배경 패널이나 시즌 이벤트 카드에 쓰면 "항구의 본부" 같은 느낌을 줄 수 있습니다.
- 방 찾기 / 방 생성
  정돈된 선실 이미지는 매치메이킹 모달의 헤더 아트나 empty state 배경으로 적합합니다.
- 패배 / 이탈 / 재접속 실패
  훼손된 선실 이미지는 패배 화면, 강제 종료, reconnect grace 만료, 포기 확인 모달에 감정선이 잘 맞습니다.
- 라운드 결과 / 트릭 종료
  갑판 이미지는 "막 트릭이 끝난 직후" 같은 전장 감정에 잘 맞아서 라운드 결과와 이벤트 다이얼로그에 쓰기 좋습니다.
- 아이콘 세트
  Figma 안의 해적 UI 아이콘은 Ready, Invite, Spectator, Bonus, Advanced Rule, Result Badge를 통일하는 데 우선 사용하면 효과가 큽니다.
